# Русификатор Creeper World 4

Любительский перевод [Creeper World 4](https://store.steampowered.com/app/848480/Creeper_World_4/) на русский язык: весь сюжет кампании и интерфейс. Перевод выполнен вручную, с учётом лора серии и характеров персонажей.

**[⬇ Скачать последнюю версию](../../releases/latest)**: файл `CW4_Russian_v1.0.zip` в разделе Assets.

Проверено на версии игры 2.5.1 (Windows, Steam).

## Что переведено

- **Сюжет кампании «Экспедиция Фарсайт».** Пролог, 20 миссий и эпилог: сообщения A.D.A. и директора Хейла, реплики Дану, переговоры Сержанта, Хиппи и Проповедника, журналы и инфокэши.
- **Интерфейс.** Главное меню, настройки, панели юнитов, справка по каждой постройке, подсказки на картах, горячие клавиши.
- **Редактор миссий, MVerse и достижения**, а также описания встроенных карт.

Не переводятся карты из онлайн-базы и миссии из генератора (их тексты пишут игроки), а также отдельные строки, которые игра собирает из кусков на лету.

### Принципы перевода

- Названия ресурсов и игровые имена собственные остаются в оригинале: **Liftic, Bluite, Redon, Greenar, Arg, ERN, TERP, CPACK, Chronom, Mark V**. Так проще пользоваться вики и англоязычными гайдами.
- Постройки и термины переведены на русский: Башня, Добытчик, Пушка, Мортира, ПВО, Снайпер, Нуллификатор, Тотем, Крипер, Антикрипер.
- У каждого ИИ свой голос: рубленые приказы Сержанта, пацифизм Хиппи и «святой» язык Проповедника с намеренными ошибками. Его клич звучит как *«ХВАЛА ОСНОВАТЕЛЯМ!»*.

## Установка

1. Скачайте `CW4_Russian_v1.0.zip` со [страницы релизов](../../releases/latest) и распакуйте. Внутри будет папка `CW4_Russian`.
2. Откройте папку игры. В Steam: ПКМ по Creeper World 4 → **Управление → Просмотреть локальные файлы**. Там лежит `CW4.exe`.
3. Скопируйте **всё содержимое** папки `CW4_Russian` в папку игры, рядом с `CW4.exe`.
4. Запустите игру как обычно.

> **Первый запуск** после установки длится 1–3 минуты. Загрузчик модов BepInEx готовит файлы под вашу версию игры и скачивает библиотеки Unity, поэтому нужен интернет. Окно игры может появиться не сразу, просто подождите. Дальше игра запускается как обычно.

### Удаление

Удалите из папки игры: `BepInEx`, `dotnet`, `winhttp.dll`, `doorstop_config.ini`, `.doorstop_version`, `arialuni_sdf_u2019` и `CW4_Русификатор_README.txt`.

Чтобы временно отключить перевод, ничего не удаляя, поставьте `enabled = false` в `doorstop_config.ini`.

## Частые вопросы

**Игра осталась на английском.** Проверьте, что `winhttp.dll` лежит прямо рядом с `CW4.exe`, а не во вложенной папке. Копировать нужно содержимое папки `CW4_Russian`, а не саму папку.

**Антивирус ругается на `winhttp.dll`.** Это загрузчик BepInEx (Doorstop), стандартный компонент модов для Unity-игр. Добавьте файл в исключения.

**После обновления игры перевод пропал или игра не запускается.** Удалите папки `BepInEx\interop` и `BepInEx\cache`: BepInEx пересоздаст их при следующем запуске.

**Где журнал для поиска проблем?** В файле `BepInEx\LogOutput.log`. Окно консоли BepInEx отключено. Чтобы включить его, поставьте `Enabled = true` в разделе `[Logging.Console]` файла `BepInEx\config\BepInEx.cfg`.

**Влияет ли мод на достижения и сохранения?** Нет. Мод только подменяет текст на экране.

**Нашёл ошибку в переводе.** Создайте [issue](../../issues), лучше со скриншотом.

## Как устроен перевод

Мод использует [BepInEx 6](https://github.com/BepInEx/BepInEx) (IL2CPP) и [XUnity.AutoTranslator](https://github.com/bbepis/XUnity.AutoTranslator). Файлы игры не изменяются: текст подменяется во время работы по словарю. Онлайн-переводчики отключены, весь перевод берётся из файлов этого репозитория.

| Файл | Содержимое |
|---|---|
| [`BepInEx/Translation/ru/Text/cw4_story.txt`](BepInEx/Translation/ru/Text/cw4_story.txt) | сюжет и миссии |
| [`BepInEx/Translation/ru/Text/cw4_ui.txt`](BepInEx/Translation/ru/Text/cw4_ui.txt) | интерфейс |
| [`BepInEx/config/AutoTranslatorConfig.ini`](BepInEx/config/AutoTranslatorConfig.ini) | настройки переводчика: русский язык, шрифт с кириллицей, без онлайн-сервисов |
| [`BepInEx/config/BepInEx.cfg`](BepInEx/config/BepInEx.cfg) | настройки BepInEx: консоль отключена |

Формат словаря: `Английский текст=Русский текст`, одна строка на запись. Внутри текста `\n` означает перенос строки, а `\=` — знак «равно». Строки, начинающиеся с `r:`, это регулярные выражения для текста с числами. Правки подхватываются после перезапуска игры.

Хотите помочь? Присылайте pull request с правками словаря.
